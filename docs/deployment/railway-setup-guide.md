# راهنمای گام‌به‌گام آماده‌سازی و استقرار در پلتفرم Railway (T-066)

این راهنما مراحل کامل راه‌اندازی، اتصال دیتابیس، استقرار کانتینری و ایجاد Volume پایدار برای مدیا در پلتفرم Railway را تشریح می‌کند.

---

## ۱. ایجاد پروژه و سرویس دیتابیس PostgreSQL
1. وارد داشبورد [Railway](https://railway.app) شوید و روی **New Project** کلیک کنید.
2. گزینه **Provision PostgreSQL** را انتخاب کنید تا سرویس دیتابیس اختصاصی ساخته شود.
3. در تب **Variables** سرویس Postgres، متغیر `DATABASE_URL` به صورت خودکار ایجاد و در شبکه داخلی در دسترس قرار می‌گیرد.

---

## ۲. اتصال مخزن گیت‌هاب و سرویس وب
1. در داشبورد پروژه، روی **Add a Service** (یا کلید `+`) کلیک کرده و گزینه **GitHub Repo** را انتخاب کنید.
2. ریپازیتوری پروژه را انتخاب کرده و برنچ استقرار (`main` یا `master`) را به آن متصل نمایید.
3. فایل مانیفست `railway.toml` در ریشه مخزن به صورت خودکار توسط پلتفرم شناسایی شده و فرآیند بیلد چندمرحله‌ای داکر و پروب `/healthz/` را مدیریت می‌کند.

---

## ۳. ایجاد و اتصال Volume پایدار برای فایل‌های مدیا (Media Storage)
1. در تنظیمات سرویس اپلیکیشن جنگو (Django Web Service)، به بخش **Volumes** بروید.
2. روی دکمه **Add Volume** کلیک کنید.
3. مسیر **Mount Path** را دقیقاً بر روی مقدار زیر تنظیم کنید:
   ```text
   /app/media
   ```
4. این پیکربندی تضمین می‌کند که تمامی فایل‌های آپلودی کاربران (رزومه‌ها و تصاویر پروژه‌ها) در چرخه‌های بازاستقرار یا ریستارت کانتینر حفظ شوند.

---

## ۴. جدول متغیرهای محیطی کلیدی (Environment Variables)

این مقادیر در تب **Variables** سرویس Web در Railway تنظیم می‌شوند:

| نام متغیر | مقدار / قالب نمونه | توضیحات |
| :--- | :--- | :--- |
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` | اتصال خودکار به سرویس PostgreSQL داخلی Railway |
| `DJANGO_SETTINGS_MODULE` | `config.settings.production` | فعال‌سازی تنظیمات ایزوله و بهینه پروداکشن |
| `SECRET_KEY` | `django-insecure-...` (رشته ۵۰+ کاراکتری) | کلید امنیتی جنگو برای امضا و نشست‌ها |
| `ALLOWED_HOSTS` | `.railway.app,portfolio.alirhw.dev` | دامنه‌های مجاز دسترسی به وب‌سایت |
| `CSRF_TRUSTED_ORIGINS` | `https://*.railway.app,https://portfolio.alirhw.dev` | دامنه‌های مجاز اعتبارسنجی CSRF |
| `PORT` | `8000` | پورت گوش دادن Gunicorn |
| `GITHUB_ACCESS_TOKEN` | `ghp_...` (اختیاری) | توکن دسترسی برای تلمتری و آمار زنده گیت‌هاب |
| `GITHUB_USERNAME` | `alirhw` (اختیاری) | نام کاربری گیت‌هاب جهت واکشی مخازن |
| `TURNSTILE_SITE_KEY` | `0x4AAAAAA...` (اختیاری) | کلید عمومی کلودفلر ترنستایل جهت گارد فرم تماس |
| `TURNSTILE_SECRET_KEY` | `0x4AAAAAA...` (اختیاری) | کلید خصوصی کلودفلر ترنستایل |
| `SENTRY_DSN` | `https://...@sentry.io/...` (اختیاری) | لینک اتصال مانیتورینگ خطاها در Sentry |

---

## ۵. اعتبارسنجی مانیفست و امنیت پروداکشن

برای اطمینان از صحت فایل کانفیگ و تطابق تنظیمات با الزامات استقرار:

```bash
# ۱. اعتبارسنجی ساختار فایل railway.toml با پایتون
python -c "import tomllib; tomllib.load(open('railway.toml', 'rb'))"

# ۲. اجرای ممیزی امنیتی استقرار جنگو
uv run python manage.py check --deploy --settings=config.settings.production
```
