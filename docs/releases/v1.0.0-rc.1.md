# Release Candidate v1.0.0-rc.1 (Milestone M3)

## Overview
Release Candidate `v1.0.0-rc.1` encompasses all engineering objectives defined across Phases 01 to 11 and successfully clears all automated quality and security gates.

## Completed Pillars & Milestones
1. **M1 (Architecture Baseline):**
   - Layered clean Django modular architecture (`apps/portfolio`, `apps/contact`, `apps/core`, `integrations/github`).
   - Bidirectional i18n & RTL/LTR layout with Persian and English language switching.
   - Dual-theme system (Dark/Light) with instant FOIT prevention script and CSS variables.

2. **M2 (Core Portfolio Flows):**
   - Dynamic project showcases with slug resolution, tag filtering, and responsive grids.
   - Secure resume streaming endpoint (`/resume/download/`) with active-version fallback.
   - "Currently Building" active project tracker and timeline views.

3. **M3 (Hardening & Quality Gate):**
   - Resilient GitHub GraphQL integration with Redis/LocMem caching, circuit breaker fallback, and rate limit mitigation.
   - Interactive command-line terminal with Tab autocomplete, progressive enhancement, and zero-eval DOM safety.
   - Hardened contact form featuring honeypot spam traps, Cloudflare Turnstile captcha, IP rate limiting, and Persist-then-notify resilience.
   - Comprehensive test suite with **89.8%+** code coverage across unit, integration, and functional layers, alongside 7 critical Playwright E2E browser journey tests.
   - Full security hardening: HSTS preload, secure cookies, Content Security Policy (CSP), Permissions-Policy, binary magic bytes validation for media uploads, and WCAG 2.1 AA accessibility compliance.
